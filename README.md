    <h1>Line-Follower Group Project</h1>
    <p><strong>Course:</strong> ME 2400 - Measurements, Instrumentation, and Control</p>
    <p>This repository contains the code used for the following:</p>
    <ul>
        <li><strong>Motor Testing:</strong> Code for testing and calibrating the motors using the TB6612FNG motor driver.</li>
        <li><strong>IR Sensor Calibration:</strong> Code for setting the threshold values for the 8-channel IR sensors to ensure accurate line detection.</li>
        <li><strong>Line Follower Operation:</strong> Code that integrates the motor control and IR sensor inputs to drive the robot along a line, implementing the line-following behavior.</li>
    </ul>
